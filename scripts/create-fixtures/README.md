# Fixture creation scripts

## create-fixtures.ts

Generates all standard PDF fixtures in `fixtures/`:

```
npx tsx scripts/create-fixtures/create-fixtures.ts
```

Creates:
- `fixtures/no-fields.pdf` — no AcroForm fields (rejected immediately)
- `fixtures/xfa-acroform.pdf` — AcroForm with `/XFA` entry (rejected)
- `fixtures/sig-empty.pdf` — form with empty signature field (accepted)
- `fixtures/sig-populated.pdf` — form with populated signature (rejected)
- `fixtures/prefilled-field.pdf` — fields with pre-filled values for privacy tests
- `fixtures/school-enrolment.pdf` — 10-field bilingual EN/MS form
- `fixtures/clinic-registration.pdf` — 22-field primary Nov 17 fixture
- `fixtures/us-community-clinic.pdf` — 14-field US clinic form

## encrypted.ts

Generates `fixtures/encrypted.pdf` using **qpdf** (must be installed separately).

```
npx tsx scripts/create-fixtures/encrypted.ts
```

**Tool:** qpdf (https://qpdf.readthedocs.io/)  
**Version pinned:** any qpdf 11.x  
**Source file:** a minimal 2-field AcroForm PDF created by this script  
**Passwords:**
- User password: `fixture-open-only`
- Owner password: `fixture-owner-only`  
**Command:** `qpdf --encrypt <user-pw> <owner-pw> 256 -- input.pdf output.pdf`  
**Verification:** open `fixtures/encrypted.pdf` in a PDF viewer; it should prompt for a password. Enter `fixture-open-only` to verify it opens correctly.  
**Note:** AES-256 encryption uses a random IV; re-running produces a byte-different but structurally equivalent PDF.
