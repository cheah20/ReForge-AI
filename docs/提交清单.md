# Kiroween 2026 提交清单（按官方规则）

截止：**马来西亚时间 2026 年 12 月 5 日早上 6:00**（太平洋时间 12 月 4 日下午 2:00），不会延期。

## 必须做到（缺一项就可能被取消资格）

- [ ] 项目全部在比赛期间（10 月 30 日之后）新做，用到的其他旧代码要在 README 里说明
- [ ] 真正用 Kiro 开发（specs、hooks、steering 等），用得太少会被取消资格
- [ ] GitHub 公开仓库 `ReForge-AI`，包含全部代码和安装说明
- [ ] 有 MIT LICENSE，并且 GitHub 仓库右侧 About 能看到 License
- [ ] 根目录有 `/.kiro`，**不能**写进 `.gitignore`
- [ ] 评审可以打开使用的在线网址（需要登录就在 Devpost 表单写账号和说明）
- [ ] 演示视频：**少于 3 分钟**、上传到 **YouTube 公开**、展示真实运行画面、不用有版权的音乐
- [ ] 全部材料用**英文**（项目介绍、视频字幕或旁白、测试说明）
- [ ] Devpost 表单选择类别：**Frankenstein**
- [ ] 写一份「How Kiro was used」说明（平时记在 `docs/kiro-usage-log.md`）

## 加分奖项（可选）

- [ ] **Blog 奖**：比赛期间发一篇公开博客，写 Kiro 和这个项目，并注明是为 Kiroween 2026 hackathon 写的

- [ ] **Best Demo 奖**：视频做得好就有机会
- [ ] **Best Student 奖**：如果你目前是在读学生
