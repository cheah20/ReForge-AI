# Kiroween 2026 Submission Checklist

Deadline: **Dec 4, 2026, 2:00 PM Pacific Time** (Dec 5, 6:00 AM in Malaysia). No extensions, no late entries.

## Must-haves

Missing any of these could get the entry disqualified.

- [ ] Everything was built during the Submission Period (after Oct 30). Any older code we reuse is disclosed in the README.
- [ ] Kiro is used for real development: specs, hooks, steering and so on. Light or token use of Kiro is grounds for disqualification.
- [ ] Public GitHub repo `ReForge-AI` with all source code and setup instructions.
- [ ] MIT license file, shown in the repo's About section.
- [ ] `/.kiro` folder at the repo root, and **not** listed in `.gitignore`.
- [ ] A live URL judges can open and try. If it needs a login, put the test account and steps in the Devpost form.
- [ ] Demo video: **under 3 minutes**, **public on YouTube**, showing the app actually running, with no copyrighted music.
- [ ] All materials in **English**: project description, video narration or subtitles, testing instructions.
- [ ] Category selected on Devpost: **Frankenstein**.
- [ ] "How Kiro was used" write-up (notes collected along the way in `docs/kiro-usage-log.md`).

## Bonus prizes (optional)

- [ ] **Blog Prize**: publish a public blog post about Kiro and this project during the Submission Period, and mention it was written for the Kiroween 2026 hackathon.
- [ ] **Social Blitz**: post on LinkedIn, X or similar. The post **must start with** `#KiroweenHackathon26`, share our favorite thing about Kiro, and be written in our own words.
- [ ] **Best Demo**: goes to the strongest video among the top-scoring entries.
- [ ] **Best Student Project**: if we're currently enrolled students.

## Judging (5 criteria, 20% each)

Potential Impact · Technological Implementation (depth of Kiro use) · Design · Innovation · Presentation
